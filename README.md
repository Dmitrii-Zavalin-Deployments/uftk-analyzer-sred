## Universal Field Toolkit Image Analyzer
An image‑processing module that performs histogram equalization, texture extraction, and feature analysis to support downstream prediction and correlation tasks.

This component is documented in **SnowPredictor: The Universal Field Toolkit**, which explains the design choices behind the analyzer and how its outputs integrate with the broader SnowPredictor system.

For full context and methodology, see: https://mybook.to/spuft
